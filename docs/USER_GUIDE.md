# User Guide

## Getting around

- **Sidebar:** Dashboard, Review queue, All pages, Tags, Analytics, How it works, Data and backup, and the five spaces (Students, Teaching, Research, Admin, IT Help).
- **Search bar:** type to search titles, tags and content. Press `/` to jump to it.
- **Role and name:** at the bottom of the sidebar. The role is simulated for demonstration.
- **Theme:** the *Theme* button cycles automatic, dark and light.

## Writing a page

1. Press **+ New page** (or `N`).
2. Choose a template, or start blank.
3. Fill in the title, space, tags and an optional review-by date.
4. Write in Markdown. The toolbar inserts headings, lists, code, quotes and a *Tips from experience* section. The preview updates as you type.
5. Add resources, one per line: `Name | https://link`. Only https links are kept.
6. Describe what you changed. It is stored in the version history.
7. **Save**, **Submit for review** (Lecturers) or **Save and publish** (Editors and Admins).

Supported Markdown: `#`, `##`, `###` headings, `-` and `1.` lists, `>` quotes, fenced code blocks, `**bold**`, `*italic*`, `` `code` `` and `[text](https://link)`.

## Reviewing

Editors and Admins open pages in **Review queue**. Choose **Approve and publish**, or write a note and **Request changes**. The author sees the request on the page and on their dashboard, edits, and resubmits.

## Version history

Every save adds a version with the author, role, time and note. Editors and Admins can **Restore** an older version (the restore itself becomes a new version, so nothing is lost).

## Search and knowledge gaps

Search ranks matches in titles above tags, spaces and body text. When a search returns nothing, the term is recorded as a **knowledge gap**. Editors see gaps under **Analytics** and can turn one into a new page with one click.

## Feedback

Readers can rate a page helpful or not, and leave comments. Editors can mark comments resolved.

## Backup

**Data and backup > Export** downloads all pages as JSON. **Import** restores them (Editors and Admins). **Erase all data** is Admin-only and asks for a second click.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `/` | Focus search |
| `N` | New page (when allowed) |
| `Esc` | Leave a field |
