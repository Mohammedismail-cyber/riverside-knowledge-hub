## What is Wiki.js?

- Modern wiki engine on **Node.js**
- **Open source** (AGPL-3.0) and self-hosted
- Markdown and visual editing
- Git-backed storage, search, single sign-on
- The **technology** part of a KMS

---

## The problem

- Notes in **chat groups**
- Policies in **PDFs**
- Answers in **inboxes**
- Lecturers leave, **know-how leaves with them**
- Departments work in **silos**

---

## The Hub: five spaces, four roles

| Spaces | Roles |
|---|---|
| Students | Student: read, comment |
| Teaching | Lecturer: write drafts |
| Research | Editor: review, publish |
| Admin | Admin: manage |
| IT Help | |

Structure plus permissions = **governance**

---

## The KM cycle

**Create → Capture → Refine → Store → Share → Apply → Feedback**

Feedback finds gaps. Gaps become new knowledge.
**The cycle restarts.**

---

## Live demo

1. Create a page from a template
2. Capture tacit knowledge in *Tips from experience*
3. Refine: request changes, approve, view history
4. Store: spaces, tags, roles
5. Share and apply: search and read as a student
6. Feedback: rate, comment, find a **knowledge gap**

---

## Strengths and limits

| Strengths | Limits |
|---|---|
| One searchable source of truth | Needs an admin and a database |
| Preserves know-how | No formal approval workflow |
| Git backup, history | Analytics need external tools |
| Free and open source | Not for confidential records |
